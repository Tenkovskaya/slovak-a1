# Slovenčina A1

Подготовка к тесту по словацкому языку A1 / Slovak A1 test practice.

Тест с объяснениями, режим экзамена, тренажёр, письменные задания, грамматика, карточки с интервальным повторением и план до теста. Интерфейс на русском и английском.

Сайт работает как приложение: на телефоне откройте его и выберите «На экран „Домой“» (iPhone) или «Установить приложение» (Android). После первого открытия работает без интернета.

Прогресс хранится только в браузере устройства.
