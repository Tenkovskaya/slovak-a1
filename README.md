# Slovenčina A1 · A2

Подготовка к тесту по словацкому языку A1 и A2 / Slovak A1 and A2 test practice.

Уровень выбирается на главной странице или переключателем A1 / A2 над уроками. Каждый уровень — свои уроки 1–6, вопросы, письменные задания, грамматика и карточки; прогресс по уровням хранится отдельно.

- **A1** — учебник «Tri, dva, jeden – slovenčina A1».
- **A2** — учебник «Tri, dva, jeden – slovenčina A2»: степени сравнения, plurál, lokál, inštrumentál, genitív, datív, posesívne adjektíva, ordináliá a dátum, slovosled; 576 вопросов, 19 письменных заданий, 1136 слов из словаря учебника и два режима тренажёра (падежи ед. ч., степени сравнения).

Тест с объяснениями, режим экзамена, тренажёр, письменные задания, грамматика, карточки с интервальным повторением и план до теста. Интерфейс на русском и английском.

Сайт работает как приложение: на телефоне откройте его и выберите «На экран „Домой“» (iPhone) или «Установить приложение» (Android). После первого открытия работает без интернета.

Прогресс хранится только в браузере устройства.
